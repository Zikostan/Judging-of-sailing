# Приложение для судейства парусных регат

## API Endpoints

Все маршруты API имеют префикс `/api/v1`. Защищённые маршруты требуют валидный JWT-токен в заголовке `Authorization`.

### Публичные маршруты

| Метод | Путь | Описание |
|--------|------|----------|
| `POST` | `/api/v1/auth/register` | Регистрация нового пользователя |
| `POST` | `/api/v1/auth/login` | Аутентификация и получение JWT-токена |

### Документация Swagger

| Метод | Путь | Описание |
|--------|------|----------|
| `GET` | `/swagger/doc.json` | Спецификация Swagger/OpenAPI в формате JSON |
| `GET` | `/swagger/` | Интерактивная документация Swagger UI |

### Защищённые маршруты

#### Регата

| Метод | Путь | Описание |
|--------|------|----------|
| `GET` | `/api/v1/regattas` | Получить список всех регат |
| `POST` | `/api/v1/regattas` | Создать новую регату |
| `GET` | `/api/v1/regattas/{id}` | Получить регату по ID |
| `PUT` | `/api/v1/regattas/{id}` | Обновить существующую регату |
| `DELETE` | `/api/v1/regattas/{id}` | Удалить регату |

#### Категория

| Метод | Путь | Описание |
|--------|------|----------|
| `GET` | `/api/v1/categories` | Получить список всех категорий |
| `POST` | `/api/v1/categories` | Создать новую категорию |
| `GET` | `/api/v1/categories/{id}` | Получить категорию по ID |
| `PUT` | `/api/v1/categories/{id}` | Обновить существующую категорию |
| `DELETE` | `/api/v1/categories/{id}` | Удалить категорию |

#### Яхтсмен

| Метод | Путь | Описание |
|--------|------|----------|
| `GET` | `/api/v1/regattas/{regatta_id}/sailors` | Получить список яхтсменов для конкретной регаты |
| `GET` | `/api/v1/regattas/{regatta_id}/sailors/find` | Найти яхтсмена по номеру класса в рамках регаты |
| `POST` | `/api/v1/sailors` | Создать нового яхтсмена |
| `GET` | `/api/v1/sailors/{id}` | Получить яхтсмена по ID |
| `PUT` | `/api/v1/sailors/{id}` | Обновить данные яхтсмена |
| `DELETE` | `/api/v1/sailors/{id}` | Удалить яхтсмена |

#### Группа заездов

| Метод | Путь | Описание |
|--------|------|----------|
| `GET` | `/api/v1/regattas/{regatta_id}/race-groups` | Получить список групп заездов для конкретной регаты |
| `POST` | `/api/v1/race-groups` | Создать новую группу заездов |
| `GET` | `/api/v1/race-groups/{id}` | Получить группу заездов по ID |
| `POST` | `/api/v1/race-groups/{id}/start` | Запустить группу заездов |
| `POST` | `/api/v1/race-groups/{id}/finish` | Завершить группу заездов |
| `DELETE` | `/api/v1/race-groups/{id}` | Удалить группу заездов |

#### Заезд

| Метод | Путь | Описание |
|--------|------|----------|
| `GET` | `/api/v1/race-groups/{group_id}/races` | Получить список заездов для конкретной группы |
| `POST` | `/api/v1/races` | Записать новый заезд |
| `GET` | `/api/v1/races/{id}` | Получить заезд по ID |
| `PATCH` | `/api/v1/races/{id}/result` | Обновить результат заезда |
| `POST` | `/api/v1/races/{id}/link-sailor` | Привязать яхтсмена к заезду |
| `DELETE` | `/api/v1/races/{id}` | Удалить заезд |

#### Документ
