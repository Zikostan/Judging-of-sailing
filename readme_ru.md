# Приложение для судейства парусных регат

## API Endpoints

Все маршруты API имеют префикс `/api/v1`. Защищённые маршруты требуют валидный JWT-токен в заголовке `Authorization`.

### Публичные маршруты

| Метод | Путь | Описание |
|--------|------|----------|
| `POST` | `/api/v1/auth/register` | Регистрация нового пользователя |
| `POST` | `/api/v1/auth/login` | Аутентификация и получение JWT-токена |

### Документация Swagger

| Метод | Путь | Описание |
|--------|------|----------|
| `GET` | `/swagger/doc.json` | Спецификация Swagger/OpenAPI в формате JSON |
| `GET` | `/swagger/` | Интерактивная документация Swagger UI |

## Конфигурация

Сервер настраивается через переменные окружения. Обязательные секреты **не имеют значений по умолчанию** — без них сервер завершается с ошибкой, поэтому он не может запуститься в продакшене с известным дефолтным паролем или ключом подписи.

| Переменная | Обязательна | По умолчанию | Описание |
|------------|-------------|--------------|----------|
| `SERVER_ADDR` | нет | `:8080` | Адрес прослушивания HTTP-сервера |
| `DATABASE_URL` | **да** | — | Строка подключения к PostgreSQL |
| `JWT_SECRET` | **да** | — | HMAC-ключ для подписи JWT-токенов |
| `JWT_EXPIRATION` | нет | `24h` | Время жизни токена (Go duration) |
| `MIGRATION_PATH` | нет | `file://migrations` | Путь к SQL-миграциям |
| `ALLOWED_ORIGINS` | нет | `*` | Значение `Access-Control-Allow-Origin` |

### Локальная разработка

```bash
cd backend
cp .env.example .env   # затем впишите реальные DATABASE_URL и JWT_SECRET
go run ./cmd/server
```

Файл `.env` подхватывается автоматически через [godotenv](https://github.com/joho/godotenv) и указан в `.gitignore`. Никогда не коммитьте реальные секреты.

Сгенерировать надёжный JWT-секрет:

```bash
openssl rand -hex 32
```

### Продакшен

Секреты стоит передавать через механизмы платформы, а не через файл `.env`: Docker/Swarm secrets, Kubernetes `Secret` или хранилище секретов (Vault, AWS/GCP Secret Manager). Приложение в любом случае читает их из переменных окружения — меняется только источник значений.
