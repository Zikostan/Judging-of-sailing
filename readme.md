# Сущности судейского приложения

## Пездюк
- **id** – уникальный идентификатор
- **Фамилия**
- **Имя**
- **Отчество**
- **Пол**
- **Возраст**
- **Класс**
- **Номер на парусе**
- **Документы_id** – ссылка на сущность «Документы»
- **id_гонки[]** – массив ссылок на сущность «Гонка»

## Документы
- **id**
- **Сам документ** – файл или набор файлов
- **Статус** (+/-)
- **Секретарь_id** – ссылка на сущность «Секретарь»

## Гонка
- **id**
- **Пездюк_id** – ссылка на сущность «Пездюк»
- **Время**
- **Судья_id** – ссылка на сущность «Судья»
- **Название гонки**
- **Даты**

## Секретарь
- **id**
- **ФИО**
- **Главный_id** – возможно, ссылка на другого секретаря
- *(Получает данные пиздюка на проверку)* – примечание

## Вид гонки
- **id**
- **Судья_id** – ссылка на сущность «Судья»
- **Секретарь_id** – ссылка на сущность «Секретарь»
- **Возраст** – диапазон
- **Пол**

## Судья
- **id**
- **ФИО**
- *(Данные судьи)* – примечание

---

## Связи между сущностями (на основе рёбер Canvas)

| От             | К             | Метка / Описание                                                                 |
|----------------|---------------|----------------------------------------------------------------------------------|
| Документы      | Пездюк        | (без явной метки)                                                               |
| Пездюк         | Секретарь     | (без явной метки)                                                               |
| Секретарь      | Пездюк        | доступ к редактированию данных пездюка (предыдущие значения сохраняются в кэше) |
| Секретарь      | Документы     | Смена статуса                                                                   |
| Секретарь      | Гонка         | После подтверждения всех данных                                                 |
| Судья          | Гонка         | (без явной метки)                                                               |
| Судья          | Секретарь     | (без явной метки)                                                               |
| Секретарь      | Вид гонки     | (без явной метки)                                                               |

> **Примечание:** рёбра отражают не только внешние ключи, но и бизнес-логику взаимодействия сущностей (например, изменение статуса, доступ к редактированию).
